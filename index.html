TUN Installer v1.0.0 stable
Proxmox LXC · Shell script

Installa TUN
e Tailscale
in un click

Abilita il dispositivo /dev/net/tun e installa Tailscale in un container LXC Proxmox con un singolo comando dall'host. Niente configurazione manuale.

Bash Proxmox VE LXC Tailscale Debian / Ubuntu
# esegui dal Proxmox host come root
curl -fsSL https://raw.githubusercontent.com/veronne2010/LXCProxmoxCT_tunInstaller/refs/heads/main/tun_installer-ITA.sh | sudo bash
Esegui dall'host Proxmox, non dall'interno del container. Assicurati che curl sia disponibile.
Root sul Proxmox host
Container Debian/Ubuntu
curl sull'host
Internet dal container
Come funziona
01
Ferma il container
Lo script spegne il container selezionato prima di modificarne la configurazione Proxmox.
pct stop $CTID
02
Abilita TUN
Aggiunge le direttive cgroup2 e mount.entry al file .conf del container.
lxc.cgroup2.devices.allow: c 10:200 rwm
03
Installa Tailscale
Riavvia il container, installa Tailscale e avvia il daemon. Segui il link per autenticare il nodo.
tailscale up → auth link
